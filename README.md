## Running locally

No build tools or dependencies — just open the file:

```bash
git clone https://github.com/iamkrish001/KrishBhurtelPortfolio.git
cd KrishBhurtelPortfolio
open index.html   # or double-click it, or use a local server:
python3 -m http.server 8000
```

## Deployment

Hosted on **GitHub Pages**, served from the `main` branch. Any push to `main` redeploys the live site automatically within a minute or so.
